# Project 0 acceptance checklist

- [ ] Uploaded CricketGraphicsStudioPremiumV2 remains unchanged.
- [ ] New repository exists separately.
- [ ] `npm install` succeeds.
- [ ] `npm run dev` starts Web on 3000, Controller on 3001, Overlay on 3002.
- [ ] All apps run without Supabase/environment credentials.
- [ ] Controller UX demonstrates touch-first contextual action-sheet direction without pretending to be official scoring.
- [ ] Shared ID/domain types exist.
- [ ] Draft fixture launch and scoring intent contracts exist.
- [ ] Scoring-engine boundary exists but refuses to perform unofficial calculations.
- [ ] CGS migration matrix explicitly records keep/redesign/replace decisions.
- [ ] Match event, realtime and source-of-truth boundaries are documented.
- [ ] No rankings, stats or database tables are prematurely implemented.

When these pass, Project 1 starts with the central identity/competition database schema.
